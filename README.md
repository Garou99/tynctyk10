# Встреча — случайный видеочат

Приложение для регистрации и случайных видеозвонков с необязательным входом гостем. Сервер хранит аккаунты в локальном JSON-файле, пароли хешируются с помощью `scrypt`, сессии используют HTTP-only cookie. Видео и звук передаются напрямую между браузерами через WebRTC; Socket.IO используется для подбора пары и обмена сигналами.

## Запуск

Нужен Node.js 18 или новее.

```powershell
npm install
$env:SESSION_SECRET = "вставьте-длинную-случайную-строку"
npm start
```

Откройте `http://localhost:3000`. Создайте аккаунт с Gmail или выберите вход гостем; в обоих случаях укажите год рождения, подтверждающий возраст 18+. Для локальной разработки переменная `SESSION_SECRET` необязательна; при публикации сайта задайте собственный секрет и включите HTTPS.

## Возможности

- Регистрация и вход по Gmail и паролю; регистрация запрашивает имя, фамилию и год рождения.
- Гостевой вход без Gmail и пароля с автоматическим именем; сервер проверяет, что пользователю исполнилось 18 лет.
- Подбор двух подключённых пользователей, отображение количества пользователей онлайн и переключение на следующего собеседника.
- Видеозвонок WebRTC с отдельными кнопками микрофона и камеры.
- Аккаунты хранятся в `data/users.json`. Файл создаётся при запуске и исключён из Git.

Адрес Gmail проверяется по формату, но не подтверждается письмом: для подтверждения владения адресом нужно отдельно подключить почтовый сервис. Пароли нельзя восстановить через форму.

## Важно для публикации

Это локальный прототип, а не готовая к публичному запуску инфраструктура: файловое хранилище рассчитано на один процесс и не заменяет базу данных; добавьте ограничение частоты запросов, проверку email, резервное копирование и мониторинг перед публичным запуском. Для работы камеры и микрофона на других устройствах нужен HTTPS. Приложение использует бесплатный STUN-сервер для установления прямого WebRTC-соединения; для более надёжной связи в сетях с ограничениями настройте TURN-сервер. Для публичного сайта также задайте переменную `SESSION_SECRET` и используйте HTTPS.

## Демо на Render

В корне есть `render.yaml` для бесплатного web service. Создайте GitHub-репозиторий, загрузите в него проект и в Render выберите создание Blueprint из этого репозитория. Render создаст случайный `SESSION_SECRET` автоматически.

Бесплатный сервис может засыпать при простое. Его файловая система не является постоянным хранилищем: тестовые аккаунты могут пропасть после перезапуска или нового развёртывания. Не используйте демо для реальных аккаунтов; для постоянного хранения потребуется подключить базу данных или постоянный диск.

Для видеосвязи в сетях, где прямой WebRTC заблокирован, создайте Metered TURN credential и задайте в Render переменные `METERED_TURN_USERNAME` и `METERED_TURN_CREDENTIAL`. Их значения хранятся в настройках сервера и выдаются только авторизованному участнику при подключении; не публикуйте их в GitHub.
